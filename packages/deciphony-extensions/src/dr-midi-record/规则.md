# dr-midi-record 规则

MIDI 实时录制，只产出钢琴大谱表：每行一个 grandStaff（花括号），staves[0] 高音谱号 = 右手，staves[1] 低音谱号 = 左手。

## 用法

```ts
import {createMidiRecorder, connectWebMidi} from '@deciphony/extensions/dr-midi-record'

const recorder = createMidiRecorder({
  bpm: 90,
  timeSignature: TimeSignatureTypeEnum['4/4'],
  measuresPerLine: 4,
  onAppend(e) {
    // e.staffIndex / e.pieces[i].{grandStaffIndex, measureIndex, slotIndex} / e.tieIds / e.layoutChanged
    triggerRef(scoreRef) // musicScore 原地修改，宿主用 shallowRef + triggerRef
  },
})
scoreRef.value = recorder.start()
const midi = await connectWebMidi(recorder)
// ... 弹奏
const score = recorder.stop()
midi.disconnect()
```

没有 MIDI 设备时也可以直接 `recorder.noteOn(midi)` / `noteOff(midi)`（如电脑键盘）。

## 时间与量化

- 时间单位 unit256：四分 = 64，全音符 = 256；`msPerUnit = 60000 / bpm / 64`
- 起点：默认 `start()` 时刻 + `startDelayMs`（宿主预备拍，如延时一拍传 `60000 / bpm`）；`startOnFirstNote: true` 时以第一个音为起点（忽略延时）
- 预备拍内就开始检测：起点前 `earlyToleranceMs`（默认半拍）以内按下的音记在第 1 拍（可以提前一点按），更早的忽略（连同其松键）
- `quantize` = 网格 = 最小音符（4 / 8 / 16 / 32，默认 16）；结束 = 最晚松键时间就近网格，至少一个网格
- **拍点吸附**：起音离拍点在 `beatSnap × 一拍`（默认 0.2）以内直接落在拍点，其余就近网格。只按网格就近时，16 分网格下晚按超过 1/8 拍就会落到拍后 16 分（多出 16 分休止）；0.2 < 0.25，真正的拍后 16 分不会被吸走
- **空档并入**：同一只手两组之间的空档短于 `minRest`（默认 2 个网格，16 分网格 = 八分）时并入前一个音，不写休止（提前松键 / 非连奏造成的碎休止）。代价：想要的短休止要停够 minRest 才会写出来
- **延迟补偿**：`latencyMs` 从所有输入时间中减去（节拍器音频输出延迟 + 人的反应），整体偏晚时用；不要和拍点吸附叠得过大
- 一组音落笔要等到「量化结束点 + minRest + 最大前吸距离」之后，保证下一组还能并入空档

## 和弦（同一 slot）

1. **触键窗口**：从一组的第一个 noteOn 起 `chordWindowMs`（默认 60ms）内按下的音算同一次触键。窗口按组的第一个音计算，不随后续音延长（防止琶音 / 快速音阶被串成一个和弦）
2. 一次触键分好左右手后，各手**量化起点相同**的音并入同一个 slot（窗口外但落在同一网格内的音也会合并）
3. 每个谱表单声部：一只手新的一组出现时，上一组还没松开的音在新起点截断

## 左右手（高 / 低音谱表）分配

不按固定分界（如 midi 60）切。每只手维护一个「位置」center（初始左 C3=48、右 C5=72）：

1. **跨度切分**：一次触键跨度 > `handSpan`（默认 12 半音）→ 在最大音程处切开，低组左手、高组右手；优先选两边都能单手按到的切点
   - 例：57 59 61 72 → 最大音程 61→72，左手 57 59 61，右手 72
2. **放得进一只手**：比较到两手位置的距离 |平均音高 − center|，取小的；附加罚分：
   - 这只手正按着的键加上这组超出 handSpan：+100（基本不选）
   - 左右手交叉（左手组高于右手位置 / 反之）：+12
3. **位置跟随**：分配后 `center = 0.5·center + 0.5·平均音高`，所以连续旋律会被同一只手「带着走」，跨过中央 C 也不会乱跳谱表
4. **回归**：一只手空闲（无按键）时位置按 3 秒半衰期回到默认

## 落笔（回调时机）

一组音在以下情况写入谱面并回调 `onAppend`：

- 全部松开，且当前时间越过其量化结束点 + 半个网格
- 同一只手出现下一组（以新起点截断）
- `stop()`

写入前先在该谱表补休止到这组的起点（一个 `kind: 'rest'` 回调）。空闲的手会随时间补休止到当前小节起点，所以只弹一只手时另一谱表也会逐小节填满。

## 记谱

- 跨小节、或时值无法用单个（附点）音符表示 → 拆段并用延音线（`createSlur`，进 `affiliatedSymbols`）连接
- 整小节休止用全休止；变音记号按调号 + 小节内记忆（`dr-midi-transfer` 的 `spell`）
- 符干方向按和弦首尾音位置；符杠按拍位自动（复拍子按附点四分）
- 需要时自动新增一行（`layoutChanged: true`）；`stop()` 补齐最后一小节、裁掉其后空小节、写终止线
