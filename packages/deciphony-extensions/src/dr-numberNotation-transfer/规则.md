线谱转简谱

1. 校验，note和noteNumber的区别之一是五线谱的chronaxie在noteInfo中，因为五线谱支持不同时值的音符在一个位置形成多声部。
   但是简谱不可以，所以简谱的chronxie在note层。所以要整体循环五线谱的音符看是否有noteInfo的chronaxie不同，如果有一个note有这种不同chronaxie的音符存在，就抛错该五线谱存在多声部，不可转换为简谱
2. 音符转为midi（固定调 / concert pitch）：
   对每个音符通过 scoreUtil 的 getNoteMidi 获取。要考虑谱号、小节调号、小节内变音记忆才能准确得到实际音高。不要依赖 dr-play。
3. midi 转换为 noteNumber（首调）：
   使用 getOctaveAndSyllable(midi, priority, **目标调**)。目标调由转换参数 `keySignature` 指定，**默认 C**。
   线谱 A 调转默认 C 简谱：concert A → 唱名 6，而不是把小节上的 A 调原样抄到简谱。
4. 调号 / 拍号层级：
   - 简谱用顶层 `MusicScore.keySignature` / `timeSignature`，小节不写调号拍号、无谱号。
   - 写入 `out.keySignature = 目标调`；拍号取源谱顶层或遇到的第一个小节拍号。
   - 删除所有小节 `keySignature_f/b`、`timeSignature_f/b`、`clef_f/b`。
5. 自定义 data：MusicScore / GrandStaff / SingleStaff / Measure 由整谱深拷贝保留；MeasureNoteSlot 的 data、lyrics 在槽位转换时再 structuredClone 过去
6. Frame：NoteSymbol/NoteRest/NoteNumber 与 NotesInfo/NotesNumberInfo 的 relativeX/Y/W/H、widthRatio、widthRatioForMeasure 双向带过；变音号重建时也带原 Accidental 的 Frame；附点对象原样引用（含 Frame）

简谱转线谱

1. 源调（首调）读顶层 `MusicScore.keySignature`，没有则用第一个小节调号，再否则 C。
   用 getNoteNumberMidi(info, **源调**) 得到 concert midi，再用 getNoteRegionAndAccidental(..., **目标调**) 写成线谱位置。
   目标调参数同样默认 C：D 调简谱转默认 C 线谱时，唱名 1 → 线谱 D，第一小节放 C 调号。
2. 去掉顶层 `keySignature` / `timeSignature`；在每个单谱表第一小节放目标调号 + 谱号；拍号只放在全曲第一个复谱表的第一个单谱表的第一小节。
   谱号：`options.clefs` 按**复谱表内**单谱表下标；默认 `[Treble, Bass, Bass, …]`（钢琴大谱表）。换算 region 时用该谱表谱号，不只是画符号。
3. 同上，各级 data 与槽位 lyrics/data 完整深拷贝；NotesNumberInfo → NotesInfo 的 Frame 不得清零（旧实现写死 0）
