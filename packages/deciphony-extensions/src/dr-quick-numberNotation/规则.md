简谱快速打谱功能

输入法设置为英文模式

1234567表示音名，空格做区分
.在音符前表示高八度，后表示低八度
,在音符后表示附点
/在音符后都表示减时线
-在音符后表示加时线
|表示小节线，|1 |2 |3 |4...依次表示 各种barline类型
(5)紧贴音符后表示同一slot位音符，比如想打个三和弦 5(6)(7)
<和>在音符前，表示连音线开始和连音线结束，相邻行为同一复谱表内容，各行为新的复谱表
[]这个符号内部的为倚音

所有字符只区分音符前后，但是字符之间并不讲究顺序。 如果写成 .[1]..5/. 那么从前到后解析，最后八度点会被低八度覆盖。

| 5. 4. <7. >6. .5(.6) | .7 .5 .5/ 5- |4 这就是一行标准的简谱单谱表
| 5. 4. <7. >6. .5(.6) | .7 .5 .5/ 5- |4

| 5. 4. <7. >6. .5(.6) | .7 .5 .5/ 5- |4
| 5. 4. <7. >6. .5(.6) | .7 .5 .5/ 5- |4 这就是两行复谱表两行单谱表

转换建议

1. 可以先通过空格将一组字符切分出来
2. 检查{}()[]这三种括号的合法性。一组字符里这三种括号必须是配套的才合法。否则不起作用

和换行形成大致结构，不解析前置小节线：|只解析成小节后置，一个|就是一个小节（前面没有音符就是空小节，行首的|也一样），如果出现 |1|2这种，后面的|2会覆盖前面的小节线

4. 对每一组字符从前到后解析含义，但是不解析<>这种跨组音符内容，这一步完成，谱子就初具雏形了

5. 解析跨组符号<>生成连音线

实现双向转换，简谱转文字的时候，由于简谱的符号>文字的规则，解析不了的就不解析
非简谱，无法转换

实现约定（规则未写明处）

- 0 为休止符，X 为节奏音符（数据模型已有，便于双向转换不丢时值）
- 单写 | 或 |0 为单小节线；|N 按常用程度：1 反复开始 2 反复结束 3 终止 4 前后反复 5 双 6 虚线 7 点线 8 反向 9 粗 10 粗双；未定义的按单小节线并给警告
- 用空格隔开的每个 | 都结束一个小节，前面没有音符就是空小节，行首的也一样（如 | | 为 2 个空小节，1 | | | | 为 4 个小节）；只有紧贴连写的 |1|2 才是后者覆盖前者；行尾最后一个 | 之后没有音符时不再补小节
- 时值：/ 每条减半；- 1 条 = 二分，2 条 = 二分 + 附点（三拍），3 条 = 全音符（渲染即 1/2/3 条加时线）；, 在此基础上加附点；- 与 / 同时出现时忽略 /
- 八度点：连续一串点为一个整体，音符前为高八度、后为低八度，后出现的覆盖前面的
- () 只在音符后生效；一个 () 内写多个数字视为多个叠音
- [] 在音符前为前倚音、音符后为后倚音；括号内点在首个数字前为高八度，数字之后（到下一个数字前）为该数字的低八度，/ 为该倚音的减时线；非首个倚音要高八度时另起一对 []，如 [1][.2]5
- {} 暂无含义，内容忽略
- 括号嵌套也视为不合法；不合法时整组的括号及括号内容都不起作用
- < > 按"复谱表内第几个单谱表"跨行 / 跨复谱表配对（栈，允许嵌套），落单的给警告
- 小节时值与拍号不符只给警告，不自动补齐
- 转文字：连音线只能标在音符位上（交叉的连音线会被重新配对）；变音记号、前置小节线无法表示，跳过并给警告；空小节写成单独一个 |
