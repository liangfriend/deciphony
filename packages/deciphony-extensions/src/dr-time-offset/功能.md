这个插件用于谱音同步。

曲谱伴奏 / 范唱播放时间不一定准，需要手动调整各 `MeasureNoteSlot.data[属性名]` 中的**绝对秒数组**，供播放高亮对齐。

## 导出

`@deciphony/extensions/dr-time-offset` → `TimeOffsetEditor` 组件（不是挂在 musicScore `:extensions` 上的扩展）。

## 时间数据

```ts
slot.data = { banZouTime: [0.5, 21.6] } // 下标 = 第几遍（0-based）
```

- 展平项用 `{ slotId, passIndex }`（`flattenKey = slotId#passIndex`）定位数组下标。
- 首次改第 2 遍且属性不存在时：写成 `[0, 0.7]`（前面补 0）。
- 兼容旧数据：单个 `number` 视为 `[number]`。

## 布局（上→下）

1. 音频波形（canvas，只画滚动可见窗口，缩放后仍清晰）
2. 展平谱（SVG：用 renderer `defaultSkin` 拼装；**按 `getPlayMeasureIndexes` 展开反复**）
3. 工具栏：`[自定义 actions…] | 前奏时间 | 重置对齐 | 播放 | 停止 | 重置 | 清除锚定（有锚定时） | 波形高度 | 横向缩放`

播放时横向滚动跟随，使播放指针尽量居中。

跨 1+2 的红色播放指针（顶部右侧显示当前秒，两位小数）；**停止时可拖** seek；播放中不可拖。

**点击波形**：指针移到该处；停止状态下再播放从这里开始，播放中直接跳过去继续播。

### 滑动条

- **波形高度**：振幅倍数 0.5–10×，只放大波形，容器高度不变（超出部分截在容器内）
- **横向缩放**：每秒像素 20–600（初值取 `pxPerSecond` prop，prop 变化时同步）；拉宽后每像素时间变短，音符分得更开；缩放时视口中心对应的时间不动

### 歌词

- 展平谱音符下方显示歌词（`slot.lyrics`），跟着音符一起拖动；有歌词的行才多留一条歌词带
- 反复第 n 遍取 `lyrics[n]`；只有一段词时每遍都显示它
- 选中音符时它的歌词高亮（蓝底白字）

### 音符编辑

- 按住音符 = 选中：上方弹出时间输入框（秒，两位小数），拖动时实时变；直接改输入框（回车 / 失焦）同样生效，规则与拖动一致
- 输入框旁「锚定 / 取消锚定」：锚定音符框为橙色；点空白处或 Esc 取消选中；锚定只在组件内存里，换时间属性时清空
- 移动规则（`createAnchorWarp`，按拖动开始时的时间计算）：
  - 拖**非锚定**音符：只动它自己
  - 拖**锚定**音符：左右最近的其它锚点为 L / R；有锚点的一侧等比伸缩（L / R 及其外侧不动），没有锚点的一侧整体平移
  - 只有一个锚点时拖它 = 所有音整体平移
  - 与被拖锚点同一时刻的音（其它谱表行）跟着一起动；被拖锚点不能越过 L / R（留 0.01s）
  - 例：1–7 锚定 1、7，拖 7 → 2–6 等比；1–9 锚定 1、5、9，拖 5 → 2–4、6–8 等比，1、9 不动

## Props

| 名 | 说明 |
|----|------|
| `audioUrl` | 音频地址 |
| `musicScore` | 曲谱（原地改 `data`） |
| `pxPerSecond` | 每秒像素初值，默认 80（组件内横向缩放滑动条可改） |
| `sampleRate` | 解码采样率（可选） |
| `timePropName` | 时间字段名，默认 `banZouTime` |
| `actions` | `{ label, onClick }[]` |

时间轴宽度固定 `600s × pxPerSecond`（最多 10 分钟）；拖拽不能超出。

## 内置播放

组件内 `APlayer` 一套；宿主测试页可另起一套，互不同步。

- **前奏时间**：秒；重置对齐时整体偏移 = 理论起奏 + 前奏时间
- **重置对齐**：按 bpm + 时值 + 反复展开写入 `data[timePropName]: number[]`（五线与简谱均支持）
- **停止**：暂停，指针保持当前位置
- **重置**：指针回 0，不改 slot 时间

## 展平

1. 用 `getPlayMeasureIndexes`（与 `mergeGrandStaff` 同源）展开反复 / volta / DC·DS 等。
2. 再按**单谱表索引**合并多列：双行复谱表无论多少列 → 2 行。
3. 同一音符多遍 → 轴上多个可拖框，各自写数组对应下标。

各复谱表的单谱表数量必须一致；不一致时提示曲谱错误，不渲染展平谱。

### 线谱 / 简谱

- **五线谱**（`StandardStaff`）：展平行画五线；符头/符干/符尾取 `defaultSkin.standardStaff`。
- **简谱**（`NumberNotation`）：展平行不画五线；数字 / 休止 `0` / 减时线 / 加时线 / 八度点取 `defaultSkin.numberNotation`（`number_0`…`number_7`、`number_X`、`reduceLine_*`、`addline`、`octaveDot`）。加时线在谱音同步里画成超短横杠（二分 1 条、全音符 2 条），仅作时值区分。时间轴拖拽与高亮逻辑与线谱相同。
