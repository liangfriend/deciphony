可以通过预设关节位置，实现虚拟2d手指动作展示

包名：`@deciphony/finger`

宿主引用（test 已 alias 到源码）：

```ts
import {Finger, FINGER_PART_LIST} from '@deciphony/finger'
```

测试页：`packages/deciphony-test/src/views/fingerTest.vue`（`App.vue` 当前挂载此页）

容器，一个svg
内部14个手指关节部件（`src/parts/*.svg`），默认都朝左：枢轴在局部坐标 (0,0)，骨段沿 -X。
整体用 SVG `transform` 驱动（`translate` 根点 → `scale(fingerSize)` → 逐关节 `rotate` → 子关节 `translate(-length,0)`）。
监测到 `thumbF` / `indexF` / `middleF` / `ringF` / `littleF` / `fingerSize` 变化后，按 `duration` 做插值过渡（`mode="edit"` 时不插值，便于拖拽）。

## 编辑模式 `mode="edit"`

展示各关节连接处控制点：

- **蓝色跟点**（每指根部，标 **1–5**：拇/食/中/无名/小）：拖拽平移，改 pose 的 `[x, y]`
- **橙色关节点**（含指尖）：拖拽绕父枢轴旋转，改对应关节角

支持 `v-model:thumb-f` 等，或监听 `@change`。

```vue
<Finger
  mode="edit"
  v-model:thumb-f="pose.thumbF"
  v-model:index-f="pose.indexF"
  v-model:middle-f="pose.middleF"
  v-model:ring-f="pose.ringF"
  v-model:little-f="pose.littleF"
  :finger-size="42"
  :width="720"
  :height="560"
/>
```

角度约定：SVG 正角为顺时针；部件图朝左，因此角度全 0 时手指朝左。

部件绘制约定（`scripts/generate-finger-parts.mjs`，改形状只改脚本再重跑）：

- 父件末端半径与子件根部半径相等，且圆心都落在子件枢轴上，任意弯曲角度轮廓都吻合
- 描边只画手指两侧，且朝根部渐隐；关节根部圆弧、非尾关节的两端一律不描边，相邻关节因此浑然一体
- 尾关节指尖是饱满的略扁圆弧，不做锥形内收；指甲偏背侧

每个手指根部一个定位点，然后加上手指部件旋转角度
大拇指两个关节部件一个定位点两个旋转角度，其余四指三个关节部件一个定位点三个旋转角度

thumbF
indexF
middleF
ringF
littleF

类型为数字数组，前两个参数是横纵坐标，之后为从根到指甲方向关节的旋转角度

使用

<Finger
:width="1000"
:height="1000"
:thumbF="[100,100,0,0]"
:indexF="[100,100,0,0,0]"
:middleF="[100,100,0,0,0]"
:ringF="[100,100,0,0,0]"
:littleF="[100,100,0,0,0]"
:duration="0.2"
:fingerSize="20"
/>

`width` / `height` 同时控制组件宽高和 svg 画布像素。
`fingerSize` 表示大拇指宽度，其余手指长宽按下面比例缩放。

手指关节比例（单位：大拇指宽度 `x = fingerSize`）

| 手指 | 宽度 | 部件长度（根→甲） |
|------|------|-------------------|
| 拇指 | 1.00x | 2.10x · 1.55x |
| 食指 | 0.80x | 2.30x · 1.35x · 0.95x |
| 中指 | 0.85x | 2.50x · 1.50x · 1.00x |
| 无名指 | 0.72x | 2.35x · 1.40x · 0.98x |
| 小指 | 0.62x | 1.95x · 1.15x · 0.90x |

原则：近节 > 中节 > 远节；中指最长、小指最短。改比例只改 `scripts/generate-finger-parts.mjs` 里 `PARTS`，再跑 `pnpm --filter @deciphony/finger generate:parts`。
