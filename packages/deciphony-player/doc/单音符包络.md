# 单音符包络（NPlayer.trigger / release / play）

用于 `trigger` / `release` 以及序列 `play` 的音量包络。时间单位均为**秒**；`0` 或不传表示该段**不存在**（无淡入/淡出含义）。

`trigger` 直连 destination，内部 gain 仍按历史约定：`实际增益 = volume × 3`。峰值再乘 `peakVolume`。

序列 `play` 的包络打在**每音 noteGain** 上，总线 `_gainNode`（`player.volume × 3`）不变，所以播放中改音量/速度仍然生效。

## 音量关系

| 量 | 计算 | 默认 |
|----|------|------|
| 维持音量 `volume` | 用户传入 | `1` |
| 峰值倍率 `peakVolume` | 用户传入；`≤0` 当作未设置 | `1.2` |
| 维持增益 | `volume × 3` | — |
| 峰值增益 | `volume × peakVolume × 3` | — |

例：`volume = 1`，`peakVolume = 1.2` → 峰值增益 `3.6`，维持增益 `3`。

## trigger：A / D / 峰值

```ts
trigger({
  midi, toneColor,
  volume?,       // 维持音量
  peakVolume?,   // 峰值倍率，默认 1.2
  attack?,       // A：秒，0→峰值
  decay?,        // D：秒，峰值→维持 volume
  release?,      // R：秒，仅当有 duration 时用
  duration?,     // 秒
  offset?, id?, onEnd?,
})
```

### A / D 组合

| A | D | 行为 |
|---|---|------|
| 有 | 无 | `0` 在 A 秒内升到**峰值**，结束瞬间切到**维持 volume** |
| 无 | 有 | 起音即**峰值**，D 秒内降到**维持 volume** |
| 有 | 有 | `0` →（A）→ 峰值 →（D）→ 维持 volume |
| 无 | 无 | 起音即为维持 volume（与旧行为一致） |

Decay **落到的就是** 设定的 `volume`（维持段），不是另一套电平。

## R 用哪一边

规则一句话：

- **设置了有效 `duration`** → 只走 **trigger 的 `release`**（在 duration 结束后淡出 `release` 秒，再停）
- **没有 `duration`** → 只走 **`release({ id, release })` 的 `release`**

| 场景 | 生效的 R | 说明 |
|------|----------|------|
| `trigger({ duration, release: R })` | trigger.R | duration 播完后再播 R 秒淡出；总长约 `duration + R` |
| `trigger({ duration })` 再 `release({ release: R })` | **不生效** | 有 duration 时提前 `release` 为立刻停止（`immediate`） |
| `trigger({ /* 无 duration */ })` 再 `release({ release: R })` | release.R | 从当前增益在 R 秒内降到近 0 再停 |
| `release` 的 R 为 0 / 不传 | — | 立刻停止 |

同 id 再次 `trigger` 会先立刻掐断旧音（不做软释放）。

## 时序示意

**仅 A，无 duration（按住后用 release.R）：**

```
gain
  ^
峰 |     *
  |    /|
维 |   / *
  |  /    \_____ ... 直到 release(R)
  | /
0 +--+----+----------> t
     A  切到维
```

**仅 D：**

```
峰 | *
  |  \
维 |   *__________
  | 
0 +--+-----------> t
     D
```

**有 duration + trigger.R：**

```
[ A/D ][==== 维持 duration ====][ R 淡出 ]→ stop
```

## 序列 play

```ts
play({
  volume?,       // 相对 velocity 的维持倍率，默认 1（不再 ×3）
  peakVolume?,   // 默认 1.2
  attack?,
  decay?,
  release?,
})
```

- 一次传入的包络套在**整首每个音符**上。无参 `play()` 沿用上次；从未传入则无包络。
- **A / D**：落在该音自己的 `duration` 内。A+D 超过 duration 时按比例缩短，不侵占 R。
- **R**：`duration` 播完之后额外的时间，再 `source.stop`。不是 duration 的一部分。
- **onEnd**：等**最后一音**的 `duration + R` 结束（该 source `onended`）才触发。手动 `stop()` 仍立即结束。
- **实时音量**：改 `player.volume` 只动总线，不取消已调度的每音 A/D/R。
- **实时 bpm / rate**：只重排**尚未起音**的音符（新 duration 上重新套包络）；已经在响的音保持原来的 stop 时刻与包络。
- 暂停最后一音时，剩余时间含尚未播完的 R，恢复后仍等到 R 结束才 onEnd。

**有 duration + R（每个序列音符都如此）：**

```
[ A/D 压在 duration 内 ][==== 维持 ====][ R 淡出 ]→ stop →（最后一音）onEnd
```

## 实现注意（快速连按）

- `AudioBufferSourceNode.stop` **只能调用一次**；无 `duration` 时不预调度 stop，以便 `release` 能软停。
- 软释放的 `setTimeout` / `onended` 用 **entry 引用** 判断：同 id 已被新 `trigger` 顶替时，只拆旧节点，**不删** map 里的新音。
- 同 id 重 `trigger` / `immediate` 会清掉旧音的兜底定时器，避免误伤新音。
