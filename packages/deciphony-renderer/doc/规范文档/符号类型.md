### 小节符号

这类符号x轴位置不能轻易改变

+ 谱号，拍号，调号，音符 且分为前置、后置、均分状态

### 游离符号

这类符号通常绑定一两个元素，且坐标通常可以拖动改变

+ 附属符号（渲染规则见 [附属符号渲染规则](./附属符号渲染规则.md)）
    + 单音符附属 这类符号特别多，变音符号，拍速等
    + 双音符附属 连音线 升降八度等
    + 单小节附属 Fine、To Coda、D.C. 等（见 [反复符号渲染](./反复符号渲染.md)）
    + 双小节附属 volta
+ 生成符号
    + 符干，符尾，符杠。 musicScore数据中无法直接展示，需要用时值等逻辑判断是否会渲染
    + 小节号：`MusicScore.measureNumber`（`{id, bracket?} & Frame`），不设不显示。从第 2 个复谱表起，在该行第一个单谱表首小节上方、水平居中于谱表最左缘显示序号 = 之前各复谱表**第一个单谱表**的小节数之和 + 1；`bracket` 为 true 时显示成 `(5)`。Frame 对所有小节号统一平移 / 扩缩。谱种无关，画在全局层（`render/measureNumber.ts`）；全量路径由 `resolveMusicScoreToVDom` 追加，增量路径由组装器追加。vDom `tag: 'measureNumber'`，所有小节号共用 `targetId = measureNumber.id`，靠 `special.measureNumber.number` 区分（已并入 `vdomSelectionKey`）。字号 = 小节高 × 0.3
