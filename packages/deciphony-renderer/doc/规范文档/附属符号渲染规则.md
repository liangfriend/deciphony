# 附属符号渲染规则

四类附属符号（单音符 / 双音符 / 单小节 / 双小节）统一由 **规则常量 + 渲染引擎** 驱动，不在渲染函数里为每种符号写 `if/switch`。

## 规则文件

`src/constants/renderRules.ts`

| 常量 | 数据挂载点 |
|------|------------|
| `SingleNoteAffiliatedSymbolRenderRule` | `NotesInfo.affiliatedSymbols`（线谱）/ `NoteNumber.affiliatedSymbols`（简谱） |
| `DoubleNoteAffiliatedSymbolRenderRule` | `musicScore.affiliatedSymbols`（连音线等） |
| `SingleMeasureAffiliatedSymbolRenderRule` | `measure.affiliatedSymbols` |
| `DoubleMeasureAffiliatedSymbolRenderRule` | `musicScore.affiliatedSymbols`（volta 等） |
| `SingleSlotAffiliatedSymbolRenderRule` | `MeasureNoteSlot.affiliatedSymbols`（琶音 / 扫弦 / 前奏括号） |
| `DoubleSlotAffiliatedSymbolRenderRule` | `musicScore.affiliatedSymbols`（踏板 / 八度记号，`startId` / `endId` = slot id） |

**挂载原则**：单宿主附属挂在宿主自身（音符 / slot / 小节）；只有跨两个宿主的附属才放 `musicScore.affiliatedSymbols`。

偏移量单位均为 **× measureHeight**。

## 音符锚点

默认相对**符头几何中心**，再加 `vertical` / `horizontal`（× measureHeight）。

简谱可在单 / 双音符规则上设 `numberNotationAnchor: 'top' | 'left' | 'right' | 'bottom'`（其它谱种忽略）：

| 值 | 含义 |
|----|------|
| `top` | 数字包围盒顶边（含上八度点；八度点变化则顶边跟着变） |
| `bottom` | 包围盒底边（含下八度点与减时线）**+ 待绘符号高度** |
| `left` | 包围盒左边（变音等计入；减时线连杠不拉宽左右） |
| `right` | 包围盒右边 **+ 待绘符号宽度** |

包围盒 = 数字框 + `VDom.numberNotationExtent`。该值由简谱 `renderSymbol` 画数字 / 休止符时写入，与八度点、减时线的实际绘制共用同一组函数（`reduceLineExtent` / `octaveDotsExtent`），引擎只读不重算，因此增量排版、Frame 平移后依然准确。改八度点 / 减时线布局时只改 `renderSymbol` 这几个函数即可。倚音暂未写 extent，按数字框计算。

双音符附属（连音线等）两端需同水平时：`top` 取更高一侧（y 更小）为基准，`bottom` 取更低一侧（y 更大）；各自 `relative*Point.y` 仍保留。跨单谱表分段（`split`）时不对齐。`left` / `right` 不做纵向对齐。

## 渲染策略 `kind`

| kind | 说明 |
|------|------|
| `skin` | 查皮肤包，生成 `tag: 'affiliation'` + `skinKey` 的 VDom，由 `Group` 组件绘制。单音符：锚点见上节，符号中心对齐锚点；单 slot（如前奏括号）：锚 slot 列起点 / 小节底 + `offset`，符号中心对齐锚点 |
| `slur` | 双音符：锚定起止音符头（简谱可用 `numberNotationAnchor`，整段 `top`/`bottom` 时两端 y 对齐到更高/更低一侧），写入 `special.slur`，由 `Slur` 组件绘制。造型由 `data.slur.style`（`SlurStyleEnum`：`rounded` 圆润 / `sharp` 尖锐）可选指定，未指定时按谱种，指定时优先于谱种。朝向 `direction` 渲染时按符干取值（不写回 data）：起止符干都向上 → `'down'`（默认控制点在两端下方，月牙往下拱），否则 `'up'`；五线谱看 `NotesInfo.direction`，鼓谱看所在声部，吉他谱符干固定向下、简谱无符干，恒为 `'up'`；默认控制点见 `slurDefaultControlPoint`。起止音符不在同一单谱表（换行 / 跨谱表）时仍只出**一个** vDom（targetId 唯一），额外写 `split: true` + `splitGap = measureHeight * 0.6`，`Slur` 把月牙从中间切成两段：左段挂起点、右段挂终点，断开处 = 起点 / 终点 ±splitGap（随端点整体平移，每段是固定形状），五线谱 / 吉他谱 / 鼓谱半段拱高为同跨度整段的 2 倍；此时 controlPoint 不起作用。`split` / `splitGap` 只在 vDom 上，不写回 `data.slur` |
| `volta` | 双小节：锚定起止小节，写入 `special.volta`，由 `Volta` 组件绘制 |

未实现的符号**不写规则项**即可，引擎遇到无规则项时静默跳过。不要批量生成占位规则。

## 渲染入口

`src/render/affiliated/engine.ts`

| 函数 | 调用时机 |
|------|----------|
| `renderSingleNoteAffiliatedSymbols` | 音符头 VDom 写入 `idMap` 之后（`renderSymbol` 内） |
| `renderSingleMeasureAffiliatedSymbols` | `renderSymbol` 之后、`processBeam` 之前 |
| `renderMusicScoreAffiliatedSymbols` | 全谱布局完成后（slur / volta / 双音符皮肤类 / 双 slot；并遍历各 slot 渲染单 slot 附属） |

**反复符号**（Coda、DC、Fine 等）不在 `affiliatedSymbols` 中，走 `measure.startRepeat` / `endRepeat`，见 [反复符号渲染](./反复符号渲染.md)。

## 双音符 / 双小节分发

`slur` 与 `volta` 在枚举中同为数值 `0`，引擎按 **锚点 id 在 idMap 中的 tag** 区分：

1. `startId` 对应 `measure` → 双小节规则（volta）
2. 否则 `startId` 对应 `noteHead` → 双音符规则（slur 等）

## 单音符规则写法

在 `SingleNoteAffiliatedSymbolRenderRule` 中**手动**添加需要的项，例如：

```typescript
[SingleNoteAffiliatedSymbolNameEnum.Staccato_above]: {
    kind: 'skin',
    skinKey: 'staccato_above',
    vertical: -1 / 8,
    horizontal: 0,
    numberNotationAnchor: 'top',
},
```

皮肤包里查不到 skinKey 时 `resolveSkinSize` 返回占位尺寸 `EMPTY_SKIN_SIZE`，照常输出 VDom，绘制成内置 empty 占位（见下文「皮肤缺失占位」）。

name 既不是内置枚举值、也不是曲谱自定义符号（如删掉的自定义符号仍被引用）时，按该种类的缺省规则（同自定义符号缺省值）定位并画占位；内置枚举值没配规则的（未实现）仍静默跳过。

## 单小节规则

`SingleMeasureAffiliatedRule`（目前内置表为空，自定义小节符号用同一套语义）：

| 字段 | 含义 |
|------|------|
| `placement` | 横向锚点：`start` 小节左边 / `center` 中点 / `end` 右边 |
| `align` | 符号哪一侧贴锚点：`left` / `center` / `right` |
| `type` | `upper`（缺省）符号底边贴小节顶；`lower` 符号顶边贴小节底 |
| `vertical` | 离开小节的距离（× measureHeight，正值远离小节） |
| `horizontal` | 横向偏移（× measureHeight，正值向右） |

## 曲谱自定义符号

三种，字段都可选（兼容旧曲谱）。每项 = 皮肤项字段（`name` 显示名、`content`、`w`、`h`、`widthRatio?`、`widthRatioForMeasure?`、`skinKey`）+ 对应内置规则去掉 `kind` / `skinKey` 后的字段：

| 种类 kind | MusicScore 字段 | 类型 | 规则字段（缺省值） | 引用它的附属 / 挂载点 |
|------|------|------|------|------|
| `note` | `extraNoteSymbol` | `ExtraNoteSymbol` | `vertical`(-0.5) `horizontal`(0) `numberNotationAnchor`(vertical>0 ? bottom : top) | `SingleNoteAffiliatedSymbol`：音符 / 休止符 `affiliatedSymbols` |
| `slot` | `extraSlotSymbol` | `ExtraSlotSymbol` | `offset: {vertical(0.5), horizontal(0)}` | `SingleSlotAffiliatedSymbol`：`MeasureNoteSlot.affiliatedSymbols` |
| `measure` | `extraMeasureSymbol` | `ExtraMeasureSymbol` | `placement`(start) `align`(left) `type`(upper) `vertical`(0.1) `horizontal`(0) | `SingleMeasureAffiliatedSymbol`：`Measure.affiliatedSymbols` |

- 引用：附属符号 `name` 填自定义符号的 `skinKey`；定位语义与同类内置 `skin` 规则完全一致（note 见「音符锚点」，slot 见 `kind` 表 skin 行，measure 见上节）。
- 缺省值只有一处：`normalizeExtraSymbol(kind, input)`，渲染与 dr-edit 创建共用。
- 实现（`src/render/extraSymbols.ts`）：`withExtraSymbols(skin, musicScore)` 把自定义符号按 `skinKey` 注入**每套** SkinPack 中当前谱种的符号表，规则挂在注入的皮肤项上（`extraKind` + `extraRule`）；引擎查不到内置规则时按种类 `extraRuleOf(skin, kind, name)` 读，固定按 `skin` 绘制。`musicScore.vue` 的 `skin` 与 `resolveMusicScoreToVDom` 都经过它，排版和绘制用同一份。
- `skinKey` 必须在三个数组里唯一；与内置符号名 / 皮肤键重名时**内置优先**、自定义不生效（dr-edit 增改时会校验拒绝）。
- `content` 与皮肤包一致：在 `w × h` 坐标里的 svg 片段；也可以是整段 `<svg viewBox=…>`，`Group` 会把根 svg 的 width / height 设成节点尺寸（内嵌 svg 只认属性，CSS 宽高无效）。

## 皮肤缺失占位（empty）

`src/skins/emptySkin.ts`：`EMPTY_SKIN_ITEM`（纯黑方框 + ×，不跟皮肤主题色）、`EMPTY_SKIN_SIZE`（12 × 12）。**不在任何皮肤包里**，内置在 renderer，所有谱种、所有符号统一使用。

- 排版：各谱种 `musicScoreToVDomImpl` 用 `withEmptySkinFallback(谱种皮肤表)` 包一层，查不到的 key 返回占位尺寸的条目（`skinKey` 仍是原 key），节点照常排版、不再被跳过；附属引擎 `resolveSkinSize` 同理。
- 绘制：`Group` 在真实皮肤表里查不到 `node.skinKey` 就画 `EMPTY_SKIN_ITEM`（按节点尺寸伸缩，节点尺寸为 0 时用 `EMPTY_SKIN_SIZE`），并在 `<g>` 上加 `data-skin-missing="原 skinKey"`，方便排查缺了哪些皮肤。
- 皮肤包缺**整套**谱种符号时（如没有 `numberNotation`），排版与绘制都回落内置 `defaultSkin` 的那套，不画占位。
- 只覆盖 `Group` 按 skinKey 画的符号；符杠、连音线、跳房子等几何组件读的是颜色键，缺失时用默认颜色，不画占位。

## Vue 层

`scoreLayer.vue`：`affiliation` 节点在 `<g>` 内按 `special` 分发；`slot` 走 `SlotOutlet`，其余 `v-else` 走 `Group`（皮肤类附属符号）。曲谱级附属画在全局层（行底层与行上层之间），见 `vDom层级与插槽.md` §1.3。
