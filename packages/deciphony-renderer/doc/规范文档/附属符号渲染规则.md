# 附属符号渲染规则

四类附属符号（单音符 / 双音符 / 单小节 / 双小节）统一由 **规则常量 + 渲染引擎** 驱动，不在渲染函数里为每种符号写 `if/switch`。

## 规则文件

`src/constants/renderRules.ts`

| 常量 | 数据挂载点 |
|------|------------|
| `SingleNoteAffiliatedSymbolRenderRule` | `NotesInfo.affiliatedSymbols`（线谱）/ `NoteNumber.affiliatedSymbols`（简谱） |
| `DoubleNoteAffiliatedSymbolRenderRule` | `musicScore.affiliatedSymbols`（连音线等） |
| `SingleMeasureAffiliatedSymbolRenderRule` | `measure.affiliatedSymbols` |
| `DoubleMeasureAffiliatedSymbolRenderRule` | `musicScore.affiliatedSymbols`（volta 等） |
| `SingleSlotAffiliatedSymbolRenderRule` | `MeasureNoteSlot.affiliatedSymbols`（琶音 / 扫弦 / 前奏括号） |
| `DoubleSlotAffiliatedSymbolRenderRule` | `musicScore.affiliatedSymbols`（踏板 / 八度记号，`startId` / `endId` = slot id） |

**挂载原则**：单宿主附属挂在宿主自身（音符 / slot / 小节）；只有跨两个宿主的附属才放 `musicScore.affiliatedSymbols`。

偏移量单位均为 **× measureHeight**。

## 音符锚点

默认相对**符头几何中心**，再加 `vertical` / `horizontal`（× measureHeight）。

简谱可在单 / 双音符规则上设 `numberNotationAnchor: 'top' | 'left' | 'right' | 'bottom'`（其它谱种忽略）：

| 值 | 含义 |
|----|------|
| `top` | 数字包围盒顶边（含上八度点；八度点变化则顶边跟着变） |
| `bottom` | 包围盒底边（含下八度点与减时线）**+ 待绘符号高度** |
| `left` | 包围盒左边（变音等计入；减时线连杠不拉宽左右） |
| `right` | 包围盒右边 **+ 待绘符号宽度** |

包围盒 = 数字框 + `VDom.numberNotationExtent`。该值由简谱 `renderSymbol` 画数字 / 休止符时写入，与八度点、减时线的实际绘制共用同一组函数（`reduceLineExtent` / `octaveDotsExtent`），引擎只读不重算，因此增量排版、Frame 平移后依然准确。改八度点 / 减时线布局时只改 `renderSymbol` 这几个函数即可。倚音暂未写 extent，按数字框计算。

双音符附属（连音线等）两端需同水平时：`top` 取更高一侧（y 更小）为基准，`bottom` 取更低一侧（y 更大）；各自 `relative*Point.y` 仍保留。跨单谱表分段（`split`）时不对齐。`left` / `right` 不做纵向对齐。

## 渲染策略 `kind`

| kind | 说明 |
|------|------|
| `skin` | 查皮肤包，生成 `tag: 'affiliation'` + `skinKey` 的 VDom，由 `Group` 组件绘制。单音符：锚点见上节，符号中心对齐锚点；单 slot（如前奏括号）：锚 slot 列起点 / 小节底 + `offset`，符号中心对齐锚点 |
| `slur` | 双音符：锚定起止音符头（简谱可用 `numberNotationAnchor`，整段 `top`/`bottom` 时两端 y 对齐到更高/更低一侧），写入 `special.slur`，由 `Slur` 组件绘制。朝向 `direction` 渲染时按符干取值（不写回 data）：起止符干都向上 → `'down'`（默认控制点在两端下方，月牙往下拱），否则 `'up'`；五线谱看 `NotesInfo.direction`，鼓谱看所在声部，吉他谱符干固定向下、简谱无符干，恒为 `'up'`；默认控制点见 `slurDefaultControlPoint`。起止音符不在同一单谱表（换行 / 跨谱表）时仍只出**一个** vDom（targetId 唯一），额外写 `split: true` + `splitGap = measureHeight * 0.6`，`Slur` 把月牙从中间切成两段：左段挂起点、右段挂终点，断开处 = 起点 / 终点 ±splitGap（随端点整体平移，每段是固定形状），五线谱 / 吉他谱 / 鼓谱半段拱高为同跨度整段的 2 倍；此时 controlPoint 不起作用。`split` / `splitGap` 只在 vDom 上，不写回 `data.slur` |
| `volta` | 双小节：锚定起止小节，写入 `special.volta`，由 `Volta` 组件绘制 |

未实现的符号**不写规则项**即可，引擎遇到无规则项时静默跳过。不要批量生成占位规则。

## 渲染入口

`src/render/affiliated/engine.ts`

| 函数 | 调用时机 |
|------|----------|
| `renderSingleNoteAffiliatedSymbols` | 音符头 VDom 写入 `idMap` 之后（`renderSymbol` 内） |
| `renderSingleMeasureAffiliatedSymbols` | `renderSymbol` 之后、`processBeam` 之前 |
| `renderMusicScoreAffiliatedSymbols` | 全谱布局完成后（slur / volta / 双音符皮肤类 / 双 slot；并遍历各 slot 渲染单 slot 附属） |

**反复符号**（Coda、DC、Fine 等）不在 `affiliatedSymbols` 中，走 `measure.startRepeat` / `endRepeat`，见 [反复符号渲染](./反复符号渲染.md)。

## 双音符 / 双小节分发

`slur` 与 `volta` 在枚举中同为数值 `0`，引擎按 **锚点 id 在 idMap 中的 tag** 区分：

1. `startId` 对应 `measure` → 双小节规则（volta）
2. 否则 `startId` 对应 `noteHead` → 双音符规则（slur 等）

## 单音符规则写法

在 `SingleNoteAffiliatedSymbolRenderRule` 中**手动**添加需要的项，例如：

```typescript
[SingleNoteAffiliatedSymbolNameEnum.Staccato_above]: {
    kind: 'skin',
    skinKey: 'staccato_above',
    vertical: -1 / 8,
    horizontal: 0,
    numberNotationAnchor: 'top',
},
```

皮肤尚未定义时 `resolveSkinSize` 返回 null，不输出 VDom。

## Vue 层

`scoreLayer.vue`：`affiliation` 节点在 `<g>` 内按 `special` 分发；`slot` 走 `SlotOutlet`，其余 `v-else` 走 `Group`（皮肤类附属符号）。曲谱级附属画在全局层（行底层与行上层之间），见 `vDom层级与插槽.md` §1.3。
