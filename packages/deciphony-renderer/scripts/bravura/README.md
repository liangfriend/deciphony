# Bravura (SMuFL reference font)

- `Bravura.otf` — download from https://github.com/steinbergmedia/bravura/releases
- Regenerate glyphs: `node scripts/extract-bravura-glyphs.mjs` (from package root)
- License: SIL Open Font License 1.1 (see release OFL.txt)

Runtime uses the generated `src/skins/generated/bravuraStandardStaff.ts`; the `.otf` is only needed to regenerate.
