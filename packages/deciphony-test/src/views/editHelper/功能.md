## 五线谱编辑功能

### 持续选中的状态

+ 音符 or 休止符, 默认音符
+ 全 二分 四分 八分 16分 32分 64分 128分 默认四分
+

### 曲谱上的添加功能

+ 曲谱末尾（g-d插槽）添加复谱表按钮，始终存在
+ hover, 鼠标移动到任意曲谱元素上都会加上一个特殊的高亮filter, 移出后取消，进入进出过程有0.2s动画 完成
+ 选中小节，进入音符添加模式
    + 鼠标移动到某一范围可以添加音符，region = 光标位置，出现一个虚拟音符提示，鼠标按下添加音符
    + 右侧出现小节属性工具栏
        + 前后插入小节
        + 反复符号添加
        + 小节线添加/修改
        + 前置谱号添加/修改
        + 前置调号添加/修改
        + 前置拍号添加/修改
        + volta添加
    + delete快捷键删除
+ 选中音符头，进入音符头选中状态
    + 按住拖拽改变region
    + 右侧出现音符头属性工具栏
        + 时值修改
        + 符杠属性（全连/右连/无）
        + 变音符号添加/修改
        + 附点添加/修改
    + delete快捷键删除
+ 选中连音线
    + 展示四个拖拽点更改连音线左右曲柄
    + 隐藏属性工具栏
    + delete快捷键删除
+ 选中其它符号
    + 隐藏属性工具栏
    + delete快捷键删除
+ 选中volta
    + 展示左右拖拽点，拖拽更换小节覆盖范围
    + 右侧出现volta属性工具栏
        + 设置反复值
        + 设置文案
    + delete快捷键删除

简谱编辑功能（numberNotation/）

+ 与五线谱共用：小节选中、插槽按钮、volta/slur 拖拽、删除快捷键
+ 简谱专有：上下拖拽更改唱名 1–7；添加节奏音符 X
+ 属性栏无符干方向；时值/减时线连接在 NoteNumber 层级

# 吉他谱和尤克里里谱
注意涉及弦的时候，尤克里里是1~4
+ 选择 标准音 琶音 扫弦 泛音 休止符， 选择时值， 选择品（选择器，x和0~27）。然后鼠标移入左键点击添加
    + 休止符只有时值
    + 其中扫弦和琶音选中后，没有品，有两个滑动条（范围1-6），表示开始弦位和结束弦位（控制ergionRange属性，这个注意展示的是1-6，实际是0-5）
    + 准备好标准音和泛音的各种品的幽灵音符（从皮肤里找到svg封装到组件），休止符要有各种时值的幽灵音符，琶音和泛音各只需要准备一个默认横穿1到6弦幽灵音符就可以
+ 选中标准音，泛音，可以更改品，（选择器，x和0~27），选中扫弦，琶音可以更改开始结束弦位
    + 添加连音线
    + beamType类型
    + 是否拍弦
    + 添加推弦符号，选择器选择推弦类型，阶段1音程和阶段2音程
+ 选中小节
    + 小节线
    + 前置拍号
+ 选中连音线，
    + 功能同简谱线谱
    + 额外增加可以更改类型(slur的type,默认无)
+ 选中推弦符号
    + 切换推弦类型，阶段一和阶段2类型
