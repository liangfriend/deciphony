    + 右侧出现小节属性工具栏
        + 前后插入小节

        + 小节线添加/修改
        + 前置谱号添加/修改
        + 前置调号添加/修改
        + 前置拍号添加/修改
        + volta添加
    + delete快捷键删除
+ 选中音符头，进入音符头选中状态
    + 按住拖拽改变region
    + 右侧出现音符头属性工具栏
        + 时值修改
        + 符杠属性（全连/右连/无）
        + 变音符号添加/修改
        + 附点添加/修改
    + delete快捷键删除
+ 选中连音线
    + 展示四个拖拽点更改连音线左右曲柄
    + 隐藏属性工具栏
    + delete快捷键删除
+ 选中琶音 / 扫弦（单 slot 附属；挂在宿主 MeasureNoteSlot.affiliatedSymbols）
    + `measure.notes` 为独立树节点（id + Frame + symbol）；列级附属绑 slot.id，符头级仍绑 symbol.notesInfo.id
    + 创建用 `createArpeggio` / `createStrumming`：默认 `relativeEndPoint.y = -measureHeight`（见 score-builder constants），避免两端重合
    + 展示垂直拖拽框：上/下控 start/end 的 y，中间框左右整体平移（scoreWriteGate + VDom patch）
    + 隐藏属性工具栏
    + delete快捷键删除
+ 选中踏板 / 八度记号 pitch（双 slot 附属；默认 x=slot 列起点，y=小节底；起止为 MeasureNoteSlot.id）
    + 展示横向拖拽框：左/右控 start/end 的 x，中间上下整体平移（HorizontalDragHandles）
    + 隐藏属性工具栏
    + delete快捷键删除

    + 隐藏属性工具栏
    + delete快捷键删除

    + 展示左右拖拽点，拖拽更换小节覆盖范围
    + 右侧出现volta属性工具栏
        + 设置反复值
        + 设置文案
    + delete快捷键删除

简谱编辑功能（numberNotation/）

+ 与五线谱共用：小节选中、插槽按钮、volta/slur 拖拽、删除快捷键

# 吉他谱和尤克里里谱
注意涉及弦的时候，尤克里里是1~4
+ 选择 标准音 琶音 扫弦 泛音 休止符， 选择时值， 选择品（选择器，x和0~27）。然后鼠标移入左键点击添加
    + 休止符只有时值
    + 其中扫弦和琶音选中后，没有品，有两个滑动条（范围1-6），表示开始弦位和结束弦位（控制ergionRange属性，这个注意展示的是1-6，实际是0-5）
    + 准备好标准音和泛音的各种品的幽灵音符（从皮肤里找到svg封装到组件），休止符要有各种时值的幽灵音符，琶音和泛音各只需要准备一个默认横穿1到6弦幽灵音符就可以
+ 选中标准音，泛音，可以更改品，（选择器，x和0~27），选中扫弦，琶音可以更改开始结束弦位
    + 添加连音线
    + beamType类型
    + 是否拍弦
    + 添加推弦符号，选择器选择推弦类型，阶段1音程和阶段2音程
+ 选中小节
    + 小节线
    + 前置拍号
+ 选中连音线，
    + 功能同简谱线谱
    + 额外增加可以更改类型(slur的type,默认无)
+ 选中推弦符号
    + 切换推弦类型，阶段一和阶段2类型

## 高频几何预览：`updateVDom` + `scoreWriteGate.patch`

拖连音线这类「指针每帧都改 Frame / 附属符号 `data`」的操作，不要每帧直接写 `musicScore`：deep watch 会整谱跑 `musicScoreToVDom`，大谱会卡死。

约定（实现见 `scoreWriteGate.ts`，连音线示例见 `renderEditSlurDrag.ts` 的 `previewSlurDrag`，垂直符号见 `renderEditArpeggioDrag.ts` / `renderEditStrummingDrag.ts`，横向符号见 `renderEditPedalDrag.ts` / `renderEditPitchDrag.ts` / `HorizontalDragHandles.vue`）：

1. **立刻改视图**：`musicScoreRef.updateVDom(targetId, patch)` —— 按 id 找到现有节点，**原地 assign**（不换数组、不换节点引用）。连音线用 renderer 的 `slurVDomPatch` 生成 patch。
2. **改源数据**：一律经 `scoreWriteGateFor(musicScore, getUpdateVDom).patch({ key, mirror?: { targetId, patch }, commit, delay? })`。默认 `delay = 100ms`，同一 `key` 只保留最后一次 `commit`；停手后再写入，整谱布局只跑一次。
3. **结构变更**（增删音符/小节等）用 `delay: 0`，立刻 `commit`。
4. **把手叠层**：拖拽中把手坐标用独立 override（如 `slurHandleOverride`），不要为了跟手去改编辑器的 `vDomList`，否则父组件重渲染 + `:extensions="[ext]"` 新数组会再次触发整谱 watch。宿主注入扩展用固定数组引用（如 `const scoreExtensions = [editExtension]`）。
5. 卸载前 `flushScoreWrites(musicScore)`，避免未落盘的 commit 丢失。
