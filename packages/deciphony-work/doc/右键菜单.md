# 元素 / 曲谱右键菜单

鼠标在 **elements**（图片 / 文本 / 音频）或 **scores**（曲谱框）上右键时，弹出自定义菜单；**自带「删除」**。

## Props

```vue
<SJWPDF
  :data="data"
  :page-index="pageIndex"
  :mode="mode"
  :context-menu="contextMenu"
  @before-context-menu="onBeforeContextMenu"
/>
```

```ts
import {ref} from 'vue'
import type {ElementContextMenuItem, ElementContextMenuPayload} from '@deciphony/work'

const contextMenu = ref<ElementContextMenuItem[]>([])

function onBeforeContextMenu(ctx: ElementContextMenuPayload) {
  // 打开菜单前按目标改写 props；payload 与 item.callback 入参相同
  if (ctx.kind === 'score') {
    contextMenu.value = [
      {text: '播放伴奏', callback: () => {}},
    ]
  } else if (ctx.element?.type === 'audio') {
    contextMenu.value = [
      {text: '音频信息', callback: (p) => console.log(p.element)},
    ]
  } else {
    contextMenu.value = [
      {text: '通用', callback: () => {}},
    ]
  }
}
```

也可静态传 `context-menu`，并用单项的 `visible?: (payload) => boolean` 过滤、`disabled?: boolean | ((payload) => boolean)` 禁用（仍显示但不可点）。

## 事件 `beforeContextMenu`

在弹菜单**之前**触发，参数为 `ElementContextMenuPayload`（与菜单 `callback` 相同）。  
宿主可在此同步替换 `:context-menu`；内部 `nextTick` 后再按最新 props 渲染菜单。

## 回调入参 `ElementContextMenuPayload`

| 字段 | 说明 |
|------|------|
| `kind` | `'element'` 或 `'score'` |
| `element` | 右键多媒体时有值 |
| `score` | 右键曲谱框时有值 |
| `vocalPerformance` | 曲谱范唱（`ResolvedScoreAudio`：src / name / author / url / file） |
| `accompaniment` | 曲谱伴奏（同上） |
| `page` | 当前页 `SPage` |
| `pageIndex` | 当前页码 |
| `data` | 整份 `SJW` |
| `mode` | `'show' \| 'edit'` |

菜单顺序：宿主 `context-menu` 各项（`visible !== false`）→ 内置「删除」（仅 **edit** 模式；元素走 `removeElement`，曲谱走 `removeScore`）。

`show` 模式：无删除项；若也没有自定义项，右键只拦截浏览器菜单、不弹自定义菜单。

整个 `.sjw-pdf` 区域（含空白、gutter）右键一律 `preventDefault`，不出现浏览器默认菜单。

缩略图预览（`Page` 的 `thumbnail`）不弹出菜单。
