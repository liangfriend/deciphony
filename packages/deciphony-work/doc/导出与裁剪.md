# 导出与裁剪

## 导出

| API（SJWPDF expose） | 结果 |
|------|------|
| `exportImages(options?)` | 单页直接 png/jpeg；多页 zip（`01.png`、`02.png`…按页码补零） |
| `exportPdf(options?)` | 一个 PDF，每页一张图 |
| `exportPageImage(pageIndex?, options?)` | 单页图片 Blob（默认当前页） |

公共参数：

| 参数 | 默认 | 说明 |
|------|------|------|
| `pages` | 全部 | 页下标数组（0-based） |
| `scale` | 2 | 输出像素 / 页面逻辑像素 |
| `filename` | — | 传了就直接下载（单页图片补 `.png`/`.jpg`，多页补 `.zip`；PDF 补 `.pdf`） |
| `onProgress(done, total)` | — | 每完成一页 |
| `onWarning(message)` | console.warn | 资源加载失败等非致命问题，该项跳过、继续导出 |
| `type`（图片） | `'png'` | `'jpeg'` 体积小 |
| `imageType`（PDF） | `'png'` | PDF 内图片编码：`png` = 无损（RGB + zlib），`jpeg` = 体积小 |
| `quality` | 0.92 | jpeg 质量 |

纯函数：`renderPageToCanvas(page, assets, options)`、`exportPagesAsImages(data, assets, options)`、`exportPagesAsPdf(...)`、`exportPageImage(page, assets, options)`、`buildPdf(pages, info)`；`assets = {getAsset, resolveSrc}`。

### 为什么不用 html2canvas / 打印

- html2canvas 自己重新实现 CSS 渲染，对 svg `foreignObject`（曲谱、文本都在里面）支持很差，结果不稳定
- `window.print()` 要弹打印对话框，拿不到文件
- 所以按**页面数据**逐层画 canvas，再自己写 PDF：结果只取决于数据，与当前显示哪页、是否在编辑无关

### 每页绘制顺序（与 `Page.vue` 一致）

1. 白底 → 背景图（拉伸铺满）
2. 曲谱：离屏挂载 renderer（扩展 / 插槽配置与 `Score.vue` 相同），克隆 svg 并内联计算样式；`foreignObject` 按实际布局转成 `<text>` / `<rect>` / 内嵌 `<svg>`（含 foreignObject 的 svg 画进 canvas 会污染画布，无法导出）；再按框位置、旋转、裁剪画进 canvas
3. 元素（按 `elements` 顺序）：图片（含裁剪）、视频首帧（取不到画黑底三角）、文本（按 `ElementNode` 的 CSS 规则排版）；**音频不画**
4. `page.drawings`（单独图层，橡皮只擦笔迹）

不导出：编辑框 / 选中态、show 模式教学标注、播放高亮、选段高亮、页面描边。

### PDF

- 自写 PDF 1.4（`export/pdfWriter.ts`），不依赖第三方库
- 页面尺寸 = 页面逻辑 px × 0.75pt（96dpi → 72dpi），打印物理尺寸与屏幕一致
- Info 写入 `SJW.name` / `SJW.author`（UTF-16 编码，中文正常）
- 每页是位图：文字不可选中；要更清晰就调大 `scale`

### 限制

- svg 画成图片后取不到页面 `@font-face`，曲谱里的标题 / 歌词等文字回退系统字体（Bravura 符号是 path，不受影响）
- http 图片 / 视频需要服务端允许跨域（CORS），否则跳过并 `onWarning`

## 裁剪

| API | 说明 |
|------|------|
| `cropImage(elementId, area, options?)` | async；area 为**原始像素**坐标；缺 `naturalWidth/Height` 时先读资源 |
| `cropScore(scoreId, area, options?)` | area 为 **musicScore.width/height** 坐标 |
| `clearCrop(id, options?)` | 取消图片 / 曲谱裁剪 |
| `cropScoreByGrandStaff(scoreId, from, to, options?)` | 按标题 / 复谱表区间裁剪：`0`=标题区，`1..n`=第几个复谱表（如 `(0,2)`=标题到第 2 个复谱表）；先后不限；用与 Score 相同的 slotConfig 排版取 Y。`keepY: true` 时框的 x/y 不动（只缩宽高），避免起点下移改掉 `score.y` |
| `getScoreVerticalBands(scoreId)` | 返回各条带 `{index,y,height}`（调试 / 预览） |

```ts
type CropArea = {startX: number; startY: number; endX: number; endY: number}
type CropOptions = {keepFrame?: boolean}
```

- 起止点先后不限；超出源范围会截断；面积为 0 抛错
- 默认（`keepFrame: false`）：保持当前显示比例，框按裁剪区域变小，裁出的内容在页面上**原地不动**（旋转也按中心换算）
- `keepFrame: true`：框不动，裁出的区域拉伸铺满
- 结果写入 `crop: {x, y, width, height}`（源坐标）；裁到整份源时删除 `crop`
- 对已裁剪的再裁：坐标仍是**源坐标**（不是相对上次裁剪）
- 返回值：实际生效的 `SCropRect`

### 裁剪模式（拖拽）

| API / 事件 | 说明 |
|------|------|
| `startCrop(id?)` | async；默认当前选中项，只能是曲谱或图片；仅 edit；绘制中抛错；图片缺原始尺寸先读资源；会结束选段 |
| `endCrop()` | 退出裁剪模式（裁剪结果保留） |
| `getCropTarget()` | 当前裁剪目标，`SjwSelection`，未裁剪为 null |
| 事件 `cropModeChange(SjwSelection)` | 进入 / 退出（null）时触发 |

- 进入后：框变橙色、隐藏旋转把手；整份源以虚线框标出，裁掉部分半透明蒙白显示；内容区仍可拖动整体移动
- 四角：nw = 起点 x / 起点 y；ne = 终点 x / 起点 y；se = 终点 x / 终点 y；sw = 起点 x / 终点 y。拖动时对角与内容在页面上不动（含旋转），可向外拖回被裁部分，截断到源范围；框最小 `EDIT_FRAME_MIN_SIZE`
- 退出：Esc / Enter（焦点在输入框时不处理）、选中别的 / 点空白、换页、切 show、开始绘制、开始选段、删除该项；右键菜单内置「裁剪」/「完成裁剪」（仅 edit，曲谱 / 图片）
- 状态在 `Page.vue`（`cropId` 恒等于 `selectedId` 或 null）；拖角改数据走 `setCropRect`，与 `cropImage` / `cropScore` 同一套比例规则
