正式环境接收 *.sjw（zip 改后缀）。

包内扁平目录：
```
work.json
21546134543.png
15489646113.png
42135446343.mp3
...
```

- zip 内资源文件名 = **缓存 id**（数字文件名）
- `work.json.assetNames`：`{ [id]: 用户自定义名称 }`（如 `xiDuoChuan.jpg`）
- 每条资源都必须有自定义名称；载入时未指定则用 `file.name`
- **笔迹**：写在 `work.json` 各页的 `pages[].drawings`（向量笔画），不单独占 zip 资源文件
- **曲谱范唱/伴奏**：文件与其它资源一样放在 zip **根目录**（id 为文件名）；元数据在 `pages[].scores[].vocalPerformance` / `accompaniment`：`{ src, name, author? }`。完整使用逻辑见 [曲谱范唱伴奏.md](./曲谱范唱伴奏.md)。

## 缓存 API

- `loadAsset(file, name?)`：原始载入 → `{ id, name }`
- 放到页面：
  - `addImage({ assetId })` / `addAudio({ assetId })` / `setBackground(assetId)`：缓存没有则失败
  - `addImageFromFile` / `addAudioFromFile` / `setBackgroundFromFile`：内部先 `loadAsset` 再放置
  - 背景 `clearBackground` / 再次 `setBackground*`：旧背景 id 若已无其它引用，从资源缓存删除

`src` / `background.src` / `thumbnail`：存的是 **id**；展示时 `resolveSrc(id)` → objectURL。http(s) / data: 原样。

导出：SJW（含 assetNames、各页 drawings）+ 缓存文件打 zip。
