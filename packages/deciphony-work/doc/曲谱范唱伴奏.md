# 曲谱范唱 / 伴奏使用逻辑

范唱、伴奏与普通图片/音频资源共用 **资源缓存 + `.sjw` 根目录文件**；曲谱上只存引用元数据，不把音频二进制嵌进 `musicScore`。皮肤同理。

## 数据怎么存

### 曲谱框 `SScore`

```ts
musicScore: MusicScore
skin?: string                   // 可选，皮肤资源 id（zip 根目录 .json = SkinPack）
vocalPerformance?: ScoreAudioRef  // 范唱
accompaniment?: ScoreAudioRef     // 伴奏

type ScoreAudioRef = {
  src: string     // 资源缓存 id = zip 根目录文件名，如 `178947076622448715885.ogg`
  name: string    // 音频展示名称
  author?: string // 作者
}
```

皮肤与图片相同：本体进资源缓存 / zip 根目录；`scores[].skin` 只存 id。`SJWPDF.addScore` 可传 SkinPack / Skin / File / assetId，对象会序列化为新 `.json` 再入库。

### 音符高亮时间（在 `MusicScore` 槽位上）

播放伴奏/范唱时，用槽位自定义时间对齐高亮（与 `dr-time-offset` 一致）：

```ts
slot.data.accompaniment = [0.5, 21.6]      // 伴奏：各遍绝对秒
slot.data.vocalPerformance = [0.5, 21.6] // 范唱
```

## 添加曲谱时（范唱 / 伴奏 / 皮肤）

`SJWPDF.addScore` / 纯函数 `addScore`：

| 传入（范唱/伴奏） | 行为 |
|------|------|
| `{ file, name?, author? }` | 先 `loadAsset(file, name)` 写入缓存，再把返回的 `id` 写成 `ScoreAudioRef.src` |
| `{ assetId, name?, author? }` | 要求缓存已有该 id；`src = assetId` |
| `{ src, name, author? }` | 要求缓存已有该 id；直接写入引用 |

| 传入（皮肤） | 行为 |
|------|------|
| SkinPack / Skin / `{ skin, skinName?, name? }` | 序列化为 `.json` → `loadAsset` → `score.skin = id` |
| `{ file, name? }` / 资源 id / `{ assetId }` | 同图片：入库或引用已有 id |

示例：

```ts
pdf.addScore({
  x: 40,
  y: 80,
  musicScore,
  skin: bambooForestSkin, // SkinPack；每次生成新的 xxx.json
  vocalPerformance: { file: vocalFile, name: '范唱.mp3', author: '张三' },
  accompaniment: { file: accFile, name: '伴奏.ogg', author: '李四' },
})
```

结果：

1. 音频与皮肤文件进入资源缓存（及日后导出 zip 根目录）
2. `score.vocalPerformance` / `score.accompaniment` 上只有 `{ src, name, author? }`
3. `score.skin` 为皮肤 json 的资源 id

## 播放

三者互斥（开一个会停另外两个）：

| API | 音频源 | 高亮时间字段 |
|-----|--------|----------------|
| `play(index?)` | MIDI（NPlayer） | 无（dr-play 序列）；默认套 `PLAY_SMOOTH_ENVELOPE`（A 0.05 / D 0.1 / 峰值 1.2 / R 0.2） |
| `playAccompaniment(index?)` | `score.accompaniment.src` → `resolveSrc` | `slot.data.accompaniment` |
| `playVocal(index?)` | `score.vocalPerformance.src` → `resolveSrc` | `slot.data.vocalPerformance` |

暂停后再点**同一模式、同一曲谱**播放会续播，不会重头。

右键菜单里可通过 `ctx.vocalPerformance` / `ctx.accompaniment`（`ResolvedScoreAudio`：含 `url`、`file`）取到解析后的音频。

## 删除曲谱

`removeScore(scoreId)`（含右键「删除」）：

1. 从 `page.scores` 去掉曲谱框
2. 收集该曲谱的范唱/伴奏/皮肤资源 id
3. 若某 id 在整份 SJW 中**已无其它引用**，则从资源缓存 `removeAsset`（多曲谱共用同一文件时保留）

## 导入 / 导出 `.sjw`

- **导出**：缓存中的音频/皮肤等文件打进 zip 根目录；`work.json` 里 score 带 `vocalPerformance` / `accompaniment` / `skin` 引用；`assetNames` 记展示名
- **导入**：`parseSjw` 把根目录文件载入缓存；按 score 上的 id 即可 `resolveSrc` / 解析皮肤 / 播放
