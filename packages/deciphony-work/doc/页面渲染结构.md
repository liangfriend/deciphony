@deciphony/work：只负责内容区（SJWPDF），按 pageIndex 展示选中页。
左侧缩略图栏由外部（如 @deciphony/test）自定义。

模式：
- show：仅渲染内容，无编辑框
- edit：elements / scores 外包通用编辑框（拖移 / 四角拉伸 / 旋转）

每页自下而上：
1. **背景 div**（白底；有图则 `<img object-fit:fill>` 拉伸铺满；`background.src` = 资源 id）
2. svg 层（曲谱 scores + 多媒体 elements；viewBox 与宽高一致，preserveAspectRatio=none）
3. canvas **持久绘制层**（透明；`page.drawings`；edit 下 `startDraw` 可交互；橡皮 destination-out）

SJWPDF 内容区（`.sjw-pdf__page-wrap`，至少铺满 SJWPDF 视口，随内容滚动）之上：
- canvas **教学标注层**（`AnnotateLayer.vue`；仅 `mode=show` 显示，叠在白板之上；**铺满整个 SJWPDF 内容区，可画到白板之外**；笔迹坐标以白板左上角为原点（可为负 / 超出页宽高），窗口变化白板重新居中时随之平移；同套 `startDraw` / `endDraw` / `setTool` / `clearDrawings`；笔迹按页缓存在内存，**不进 work.json / .sjw**；换页不丢，仅 `clearAnnotations` / show 下 `clearDrawings` 清当前页；未 `startDraw` 时 `pointer-events: none`，不挡音视频）

元素：
- 图片：addImage / addImageFromFile；src 为资源 id
- 音频：addAudio / addAudioFromFile；默认 DEFAULT_AUDIO_*；自定义 AudioPlayer
- 视频：addVideo / addVideoFromFile；原始像素写框尺寸；自定义 VideoPlayer，随框缩放
- 音频 / 文本 / 视频：默认尺寸见 constants/elementDefaults；音频、视频靠边框拖移以免挡控件
- 背景：`setBackground(id)` / `setBackgroundFromFile` / `clearBackground`；替换或清除时，旧背景图若已无其它引用则从资源缓存删除
- 曲谱：page.scores；Score.vue 内嵌 musicScore + dr-title/dr-lyrics（固定展示）；可选 `skin` 为皮肤资源 id（zip 根 `.json`），有则加载后传给 renderer；拉伸只 scale 显示
- 裁剪：图片 / 曲谱可带 `crop`（源坐标矩形），框只显示该区域并拉伸铺满；图片用嵌套 `<svg viewBox=crop>`，曲谱用内层 transform（见 `导出与裁剪.md`）
- 导出图片 / PDF 不截 DOM，按同样的层级用数据重画（见 `导出与裁剪.md`）
- 绘制 API（按 mode 分流）：startDraw / endDraw / setTool(DrawToolEnum, { color?, lineWidth? }) / clearDrawings；edit→`page.drawings`；show→教学标注；另有 `clearAnnotations` 只清标注
- 元素右键：context-menu 自定义项 + 内置删除（见 doc/右键菜单.md）
- 播放：SJWPDF 暴露 play/pause/stop/addToneColor/setToneColorName/setBpm…（内部 NPlayer + dr-play + 高亮）
- 几何：一律以中心为基准；存储仍为左上角 (x,y)+w/h
- 文本双击进入等大 textarea 编辑

静态资源与导入导出同前。
