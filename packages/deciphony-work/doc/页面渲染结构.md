@deciphony/work：只负责内容区（SJWPDF），按 pageIndex 展示选中页。
左侧缩略图栏由外部（如 @deciphony/test）自定义。

模式：
- show：仅渲染内容，无编辑框
- edit：elements / scores 外包通用编辑框（拖移 / 四角拉伸 / 旋转）

每页三层（自下而上）：
1. canvas 背景层
2. svg 层（曲谱 scores + 多媒体 elements；viewBox 与宽高一致，preserveAspectRatio=none）
3. canvas 绘制层

元素：
- 图片：addImage / addImageFromFile；src 为资源 id
- 音频 / 文本等：默认尺寸见 constants/elementDefaults；音频用自定义 AudioPlayer
- 背景：background.src 为资源 id（图片）；无则白底；setBackground / setBackgroundFromFile
- 曲谱：page.scores；Score.vue 内嵌 musicScore + dr-title/dr-lyrics（固定展示）；拉伸只 scale 显示
- 播放：SJWPDF 暴露 play/pause/stop/addToneColor/setToneColorName/setBpm…（内部 NPlayer + dr-play + 高亮）
- 几何：一律以中心为基准；存储仍为左上角 (x,y)+w/h
- 文本双击进入等大 textarea 编辑

静态资源与导入导出同前。
